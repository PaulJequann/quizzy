# Quizzy verification map

Launch through [the verify skill](../SKILL.md). All recipes start from its synthetic
reviewer and learner accounts. Read IDs from `instance.json`; do not assume production IDs.
Use the exact manifest origin, a dedicated tab, and role/label locators. Record each entry
point separately. A route skipped because its fixture is missing remains unverified.

- [Study sign-in and privacy](accounts.md) covers login, learner visibility, reviewer workspace selection, and logout.
- [Taking a quiz](study.md) covers grading, saved results, and feedback.
- [Progress](progress.md) covers mastery, results history, and reviewer preview.
- [Authoring and publication](authoring.md) covers private draft visibility and reviewer publishing.
- [Prepare next practice](teaching.md) covers grounded teaching evidence and copying.

Browser recipes use T3 preview tools. Save action transcripts, snapshots, screenshots,
and second-view persistence evidence under the launch run's evidence directory. The map
does not yet cover all subject/concept maintenance, source ingestion, PWA installation,
or MCP tool entry points. Consult route/tests source when those change; do not claim full
app coverage from the five initial recipes.
